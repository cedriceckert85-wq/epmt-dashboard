# Obsidian Setup

Use the repository root itself as the Obsidian vault.

Do NOT use `obsidian/` as a separate vault root.
This avoids broken parent-path Wikilinks and duplicate state.

Canonical machine state:
- state/project_state.json
- state/journal.jsonl
- Git SHA

Generated views:
- PROJECT_STATE.md
- CURRENT_TASK.md

Recommended dashboard file:
- obsidian/00_HOME/PROJECT_HOME.md
