# V3 Refactor — Response to External Senior Review

Normative version: V3. docs/archive/ is historical.

BLOCKER 1 (test registry): test_registry.yaml added — 51 entries covering every
symbolic required_test across all 21 phases (command, cwd, timeout_s, requires,
parser, evidence, implemented_in_phase, produces_metrics). Loader/validator in
orchestrator/test_registry.py; unit test enforces zero coverage gaps. Registry is
agent-immutable. Unmet requirements => UNVERIFIED, never skipped-as-pass.

BLOCKER 2 (acceptance binding): accepted_high_ids parameter removed. The gate
engine now takes RAW acceptance records (reports/acceptance/, agent-immutable)
and validates each itself via orchestrator/acceptance.py: phase match, exact
candidate SHA, decision==ACCEPT, all fields present. Stale/incomplete/unreadable
records surface as gate reasons. A wrongly constructed id set can no longer
bypass the gate.

BLOCKER 3 (security enforcement): orchestrator/path_policy.py added — reference
implementation of immutable-over-allowed with traversal/absolute/backslash
normalization. tests/unit/test_security.py is now a real suite (no assert True).
Runtime post-run git-diff enforcement remains Phase 00 scope by design and is a
Go/No-Go blocker.

HIGH (thin build prompts): prompts/build/phase-01..20.md fully rewritten. Each
spec: inputs, architecture, concrete files, data models, failure modes, tests
(registry-mapped), hard metrics, real-vs-mock split, human review criteria.
Phase 04 carries the full fixture matrix (100/500 ppm drift, 20% missing
samples, 2 s riot disconnect, OBS segment switch, +1 h wall-clock jump, pause).

HIGH (measurable gates): every phase 01-20 now has hard metrics in its yaml
(e.g. 07: resume_duplicate_objects==0, dropped-frames delta <=0.5pp; 08: RSS
growth caps, fd_leak==0; 09: asr_rtf_gpu<=0.35; 12: loudness -15..-13 LUFS,
encode>=1.5x). Thresholds are tunable but a change is a gate-config change.

HIGH (evaluate() dual responsibility): split into
validate_lifecycle_transition() (pure, safe for BUILDING->TESTING etc.),
evaluate_completion_gate() (PASS decision only) and validate_merge_commit().

MEDIUM: requirements-dev.txt pinned (pytest==9.1.1, PyYAML==6.0.3,
jsonschema==4.26.0). FILE_MANIFEST.md generated by scripts/generate_manifest.py
and enforced by tests/unit/test_manifest_sync.py. Windows tree-kill:
tests/fakes/fake_tree.py + tests/faults/test_process_tree_kill.md spec;
POSIX ProcessRunner behaviour unit-tested. Old audits archived.

Deliberately still Phase 00 scope (unchanged, per design): live adapters,
approve persistence, run pipeline, real 8h orchestrator soak, runtime path
enforcement wiring, Tailscale harness implementations (registry entries are
normative; implemented_in_phase marks where each harness gets built).
