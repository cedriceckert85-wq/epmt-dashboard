# Tailscale Streamer Onboarding

1. Install Tailscale on streamer PC.
2. Authenticate device into approved tailnet/account.
3. Confirm intended device identity/name.
4. Confirm Central Receiver is reachable over Tailscale.
5. Run Agent network preflight.
6. Enroll Streamer Agent and issue separate app credential.
7. Verify own-tenant upload works.
8. Verify access to another tenant is denied.
9. Run 1 GB transfer test.
10. Stop Tailscale mid-transfer.
11. Confirm upload pauses without corruption.
12. Restore Tailscale.
13. Confirm resume from verified state.
14. Run 30-minute live stream with upload.
15. Verify OBS/gameplay health remains within thresholds.

Any UNVERIFIED critical step blocks onboarding.
